Lesson 0001

ขอให้ AI ช่วยเราเป็นภาษาอังกฤษแบบชัด

เป้าหมายของบทนี้คือเขียน prompt ภาษาอังกฤษสั้นๆ ที่บอก AI ว่าเราต้องการอะไร ทำไปเพื่อใคร และอยากได้คำตอบแบบไหน

ทำไมต้องเริ่มจากโครงสร้างนี้

OpenAI แนะนำให้เขียนคำสั่งให้ชัด แยกบริบทและข้อจำกัดออกจากกัน และบอกผลลัพธ์ที่ต้องการให้ตรงงานจริง ส่วน Google Technical Writing เน้นการเขียนให้ผู้อ่านเข้าใจงานเร็ว ซึ่งใช้กับ AI ได้ดีมาก เพราะ AI ก็ต้องการคำสั่งที่ไม่กำกวมเช่นกัน

บทนี้ใช้สูตรเดียวก่อน: Act as + Task + Context + Constraints + Output

Prompt formula

Act as a [role]. [Task]. Context: [context]. Constraints: [rules]. Output: [format].

1. Act as

บอกบทบาทที่อยากให้ AI รับ เช่น Act as a writing assistant.

2. Task

บอกงานเป็นกริยาชัดๆ เช่น Rewrite this caption.

3. Context

บอกสถานการณ์ เช่น This is for a Facebook post about an online course.

4. Constraints

บอกข้อจำกัด เช่น Use simple English and keep it under 60 words.

5. Output

บอกรูปแบบคำตอบ เช่น Give me three versions in a table.

ตัวอย่างใช้งานจริง

Thai intention: ช่วยแก้แคปชันภาษาอังกฤษสำหรับโพสต์ขายคอร์ส ให้สั้น อ่านง่าย และมี 3 ตัวเลือก

Act as a writing assistant.
Rewrite this caption for a Facebook post about an online course.
Context: The audience is busy beginners who want practical lessons.
Constraints: Use simple English. Keep each version under 40 words.
Output: Give me three versions in a table.

Quiz: จากความจำ

ข้อไหนเป็น prompt ที่ชัดที่สุดสำหรับขอให้ AI ช่วยเขียนข้อความงานออนไลน์?

ฝึกทันที

เขียน prompt ภาษาอังกฤษของคุณเองจากสถานการณ์นี้: “ให้ AI ช่วยสรุปหน้าเว็บภาษาอังกฤษ แล้วบอกว่าต้องทำอะไรต่อ”

เสร็จแล้วส่ง prompt นี้กลับมาให้ผมตรวจได้ ผมจะช่วยแก้ให้เป็นธรรมชาติขึ้น
