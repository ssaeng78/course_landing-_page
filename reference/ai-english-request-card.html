AI English Request Card

โพยสั้นสำหรับเขียนคำขอภาษาอังกฤษให้ AI เข้าใจงานเร็วขึ้น

Formula:

Act as + Task + Context + Constraints + Output

Act as

Act as a writing assistant.

Act as a web designer.

Task

Rewrite this message.

Summarize this page.

Context

This is for a course landing page.

The audience is busy beginners.

Constraints

Keep it under 80 words.

Use simple English.

Output

Give me three options.

Return a table.

Sources: OpenAI prompt engineering, Google Technical Writing.
